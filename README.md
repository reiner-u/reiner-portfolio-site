# Portfolio Site

My personal site, and the reason I picked up Next.js, TypeScript, and Tailwind in the first place. Built to actually show what I've made rather than just describe it on a resume.

**Live:** [reinerumila.dev](https://reinerumila.dev)

## Stack

Next.js 16 (App Router, static export), TypeScript, Tailwind CSS v4, react-icons for the tech badges, react-markdown for the resume page. Deployed on Netlify.

## Running it

```bash
npm install
npm run dev
```

Runs on port 3000.

## Notes

This one's never really "done." Projects get added here as they're built elsewhere, the resume updates as things change, and the site keeps getting refined alongside whatever it's currently showing off.
